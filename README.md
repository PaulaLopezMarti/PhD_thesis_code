# PhD thesis code

Code used for PhD thesis "Decoding B cell malignancy susceptibility through integrative 3D epigenomics" by Paula López-Martí.

This GitHub repository is still under construction and will be updated with the final scripts in the upcoming months. 

# Repository structure

1. **B cell roadmap**: scripts and analysis relative to human B cell differentiation roadmap avaiable at [B-cell roadmap repository](https://github.com/JavierreLab/B-Cell_Roadmap)
2. **Epi-multiCOGS**: tutorial to run epi-multiCOGS in the [Wiki page](https://github.com/PaulaLopezMarti/PhD_thesis_code/wiki) *under construction*
3. **BCM epi-multiCOGS analysis**: scripts and analysis conducted for the results presented in the thesis and used for the upcoming publication: *under construction*
